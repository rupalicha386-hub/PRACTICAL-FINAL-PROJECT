# Retail Sales Dashboard – Excel Project

## 1. Project Overview

This project is a Retail Sales Dashboard created using Microsoft Excel. It analyzes retail sales data using Pivot Tables, Pivot Charts, and KPI cards.

## 2. Dashboard KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold

These KPIs provide a quick overview of business performance.

## 3. Pivot Table Analysis

### Pivot Table 1: Category and Product Analysis

The first Pivot Table summarizes quantity, unit price, discount, total sales, unit cost, and profit for each product and category.

### Pivot Table 2: Sales by Category

The second Pivot Table compares total sales across four product categories:

- Accessories: ₹69,601.50
- Home: ₹63,575
- Electronics: ₹59,377.50
- Stationery: ₹8,369

### Pivot Table 3: Sales Status Analysis

The third Pivot Table summarizes orders by sales status:

- High Sales: 40 orders
- Low Sales: 110 orders
- Total Orders: 150

## 4. Dashboard Charts

### Bar Chart

The bar chart compares total sales across product categories and helps identify the highest-performing category.

### Pie Chart

The pie chart shows the distribution of High Sales and Low Sales orders.


## 5. Conclusion

This project demonstrates how Excel can be used to organize sales data, summarize information with Pivot Tables, and present business insights through charts and a dashboard.
